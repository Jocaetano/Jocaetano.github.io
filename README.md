# Jonas Caetano Portfolio (GitHub Pages)

This repository contains a static portfolio website for **Jonas Caetano (Jocaetano)**, ready for deployment to **GitHub Pages**.

## Included

- `index.html` — one-page portfolio with About, Experience, Skills, Projects, and Contact
- `styles.css` — responsive modern styles
- `script.js` — mobile menu + dynamic footer year
- `assets/Jonas Caetano - Resume.pdf` — resume file used by the portfolio
- `.github/workflows/deploy-pages.yml` — automatic deployment workflow

## Deploy to `github.io`

### Option A (User site)

Use repository name: `jocaetano.github.io`.

- Push this project to that repository.
- GitHub Actions will deploy automatically when pushing to `main`.
- Your site URL will be: `https://jocaetano.github.io/`

### Option B (Project site)

Use any repository name (for example `portfolio`).

- Push to `main`.
- Enable **Settings → Pages → Source: GitHub Actions**.
- Your site URL will be: `https://jocaetano.github.io/<repo-name>/`

## Local preview

Open `index.html` directly in your browser, or use any static server extension in VS Code.
